# DD up: studio website (Gatsby + Strapi)

Bilingual (DE / EN) marketing website for **DD up**, a small Austrian web design and development studio. Static frontend built with Gatsby, content managed in a headless Strapi CMS.

Designed and built end to end by [Volodymyr Anton-Simeon](https://www.linkedin.com/in/volodymyr-anton-simeon-43b4a52b0/), 2023.

## Features

- **Pages:** Home, Services, Works (portfolio), project detail pages, About, Contact, 404
- **Headless CMS:** all page content, projects and services are edited in Strapi and pulled in at build time through GraphQL (`gatsby-source-strapi`)
- **Project pages generated by slug** from CMS entries (`gatsby-node.js` + `templates/work.js`), with image galleries and rich text rendered from Strapi HTML/Markdown
- **Internationalisation:** DE / EN with `react-intl`, a language switcher that keeps the current page, and localised CMS content
- **Contact form:** modal and page form with client-side validation, success and error states, and a small PHP mail handler for shared hosting
- **Responsive layout:** custom SCSS on top of a trimmed Bootstrap build, mobile navigation, video and image hero sections
- **Static export:** CMS uploads are copied into the static build, so the site can be hosted without a running CMS

## Repository structure

```
dd-up-gatsby/dd-up/
  frontend/   Gatsby 5 site (React 18, SCSS, react-intl)
  backend/    Strapi 4 CMS: content types for home, about, services, works, contact, articles
html/         First version of the site: static HTML + SCSS, built with Gulp
```

## Tech stack

**Frontend:** Gatsby 5 · React 18 · GraphQL · react-intl · SCSS / Bootstrap · gatsby-plugin-image  
**CMS:** Strapi 4 (REST + GraphQL), MySQL or SQLite  
**Other:** Gulp + Sass (static prototype), PHP mail handler

## Running locally

```bash
# CMS
cd dd-up-gatsby/dd-up/backend
cp .env.example .env   # set APP_KEYS, API_TOKEN_SALT, ADMIN_JWT_SECRET, JWT_SECRET
npm install
npm run develop        # http://localhost:1337/admin

# Website (in a second terminal)
cd dd-up-gatsby/dd-up/frontend
npm install
cp .env.example .env.development   # set STRAPI_TOKEN to a read-only Strapi API token
npm run develop        # http://localhost:8000
```

Secrets are never committed: create your own `.env` files locally.
